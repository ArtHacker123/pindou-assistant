## Context

编辑模式下点击格子 = 执行当前工具（画笔/橡皮/吸管/油漆桶/替换），单击手势已被完全占用；`PatternGrid` 在编辑模式收到的 `selectedCode` 恒为 null（`EditorScreen.kt` 传入处），因此编辑模式没有任何同色高亮。查看模式的 Form 2 聚光高亮（描边 + 压暗 + 坐标圆圈，`pattern-render` 规格）不可直接照搬：编辑模式需要看清全图才能绘画，压暗会干扰；且选色入口不同（编辑模式是底部色板/吸管设画笔，不是点击格子）。

关键突破口：底部色板选色（`selectBrush`）与画布手势是两条独立链路，画笔色号（`EditingSession.brushCode`）本身就是编辑模式的"当前选中色"。

## Goals / Non-Goals

**Goals:**
- 编辑模式选中画笔色后，画布自动给所有同色格描边高亮，帮助数格/找漏涂/分组
- 与全部编辑工具零手势冲突（点击格子仍执行工具，不新增任何画布手势）
- 可关闭（工具坞开关），关闭后行为与现状完全一致
- 高亮实时跟随：换色、涂色、擦除、替换后立即反映

**Non-Goals:**
- 不在编辑模式实现查看模式的压暗聚光/坐标圆圈（那是 Form 2 行为）
- 不新增长按/双击等画布手势
- 不改 core 模块与 `.pindou` 格式

## Decisions

### D1: 高亮对象就是当前画笔色号，复用 selectedCode 通道
`PatternGrid` 已有按 `selectedCode` 描边的渲染逻辑；编辑模式改为传入 `brushCode`（开关开启时），而不是恒传 null。换色（色板点选、吸管取色）都汇聚到 `brushCode`，高亮自动跟随，无需新接线。
- *备选*：独立的 `highlightCode` 参数——多一个状态源，与画笔联动需要手动同步，拒绝。

### D2: 编辑模式渲染为"只描边不压暗"
给 `PatternGrid` 的高亮渲染加一个"压暗未选中格"的开关参数（查看模式 true / 编辑模式 false）。匹配格保留 inset 描边（琥珀色 `SELECT_ACCENT`，与查看模式一致）；未匹配格不加黑色蒙版。`selectedPos` 在编辑模式恒为 null，圆圈标记自动不画。
- *备选*：编辑模式用更淡的压暗（如 25%）——仍干扰绘画，且多一套数值，拒绝。

### D3: 开关状态放 `EditingSession`，默认开启
`brushHighlight: Boolean` 作为编辑会话状态，由 `PindouController` 暴露；工具坞浮动栏（`FloatingToolbar`）加一个高亮开关图标（如 `Icons.Filled.Highlight`），选中态背景与工具一致。会话内持久（跨模式切换保留），不落盘。
- *备选*：每次进编辑模式重置为开——用户关掉后反复出现，烦，拒绝。

### D4: 涂色/擦除天然实时更新
`brushCode` 是状态、grid 变化触发重绘，涂上某色的格子下一帧即进入高亮集合，擦掉即退出——不需要额外订阅。

### D5: 零手势改动
所有画布手势（单击工具、拖动画笔、双指缩放、长按参考图）保持原样；高亮是纯渲染层叠加。

## Risks / Trade-offs

- **默认开启让用户觉得画布"变花"** → 工具坞一键可关；描边仅 1.5–3px inset，不遮色号文字
- **相近色格子描边后不易区分**（描边是琥珀色，底色相近时对比弱） → 与查看模式同一已知限制；后续可按需加"压暗强度"档位，本次不做
- **工具坞再加一个图标变长** → 开关放在 undo/redo 分隔线之后、画笔之前（与颜色相关的一组），坞仍可拖动避让
